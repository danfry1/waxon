waxon
Install Docs GitHub

Spotify, from the home row.

waxon is a Spotify client for the terminal with vim keys. It plays music by itself or drives the Spotify app, with album art, a spinning record and synced lyrics.

$ brew install danfry1/tap/waxon

Needs Spotify Premium. Other ways to install

M

Play it here, or drive the app.

waxon can be the player itself, so you don't need the Spotify app at all. Or it's the remote for the Spotify app, your phone or a speaker.

M switches between the two and carries on from the same second. Your keyboard's media keys and the system's Now Playing work either way.

jk

Moves like vim.

Counts, gg and G, visual mode to act on a run of tracks, / to filter any list, and : commands that suggest themselves as you type.

Every key can be remapped, and ? always shows the ones you have.

v

A record that turns.

Now Playing fills the terminal with the album art, over colours drawn from the cover. Press v and it becomes a record, turning at 33⅓ with a tonearm that tracks the song.

l

Lyrics, in time.

Synced lyrics light up line by line as the song plays. They come from lrclib, with no account or key to set up, and one setting turns them off.

gq

The queue, as you'd expect it.

What's playing, what you've queued, then what's next from the playlist. Enter skips straight to a track and keeps the rest of the queue.

waxon next

Scripts and status bars.

Every action is also a command, so waxon fits into tmux, waybar, hotkey daemons and shell scripts without opening the app. waxon status prints what's playing in any format you like.

Install

macOS, Linux and Windows. Needs Spotify Premium.

$ brew trust danfry1/tap
$ brew install danfry1/tap/waxon

Homebrew asks you to trust a third-party tap once before installing from it. Works on macOS and Linux.

$ nix run github:danfry1/waxon            # try it without installing
$ nix profile install github:danfry1/waxon
> scoop bucket add danfry1 https://github.com/danfry1/scoop-bucket
> scoop install waxon
$ go install github.com/danfry1/waxon@latest

Every release has .deb, .rpm and .apk packages, plus archives for Linux, macOS and Windows on amd64 and arm64, with SHA-256 checksums.

Run waxon

The first run is a guided setup of about a minute: sign in to Spotify in your browser, then choose where music plays.

Press ?

Help lists every key, including the ones you've remapped. The README covers the rest.

Stuck?

waxon doctor checks your login, devices, network and terminal, and says what to fix.

It talks to Spotify, and that's it.

waxon has no telemetry, analytics or update checks. Sign-in uses PKCE, so there's no client secret, and your password only ever goes to Spotify's own sign-in page.

On a work network it uses your proxy settings, and "lyrics": false keeps it to Spotify alone.

  • accounts.spotify.comSigning in
  • api.spotify.comYour library, search and playback
  • *.scdn.coAlbum and playlist covers
  • lrclib.netLyrics, looked up by the track's title, artist, album and length
  • Spotify's audio serversOnly when waxon is the player
